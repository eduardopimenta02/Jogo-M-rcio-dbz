- Descrição:
  
Goku vs Dragões é um jogo de ação eletrizante onde o lendário guerreiro Saiyajin enfrenta uma ameaça mística: dragões ancestrais que surgiram para dominar o universo. Prepare-se para lutar, voar, soltar Kamehameha e salvar o mundo em combates que exigem reflexo, estratégia e pura energia!

🕹️ Como Jogar/
Movimentação:

←: Andar para a esquerda

→ : Andar para a direita

↑: Andar para cima

↓: Andar para baixo

Ataques:

Botão esquero do mouse: kamehameha

🕹️ Características

Estilo de jogo: Ação

Número de jogadores: 1 Jogador

🛠️ Tecnologias Utilizadas

Programa Construction 3
